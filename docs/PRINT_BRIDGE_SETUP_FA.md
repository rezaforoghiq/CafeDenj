# راهنمای نصب و یکپارچه‌سازی Print Bridge برای ویندوز (فارسی)

نسخه: 1.0

این سند نحوهٔ نصب، پیکربندی و استفاده از برنامهٔ ویندوزی Print Bridge را برای چاپ خودکار برگه‌های آماده‌سازی سفارش روی چاپگرهای حرارتی توضیح می‌دهد.

---

1. مروری بر پروژه

- Print Bridge چیست؟
  - Print Bridge یک برنامهٔ کوچک ویندوزی است که به‌صورت محلی در کنار چاپگر اجرا می‌شود، درخواست‌های چاپ معلق را از وب‌سایت دریافت می‌کند و متن دریافت‌شده را روی چاپگر حرارتی چاپ می‌کند.

- چرا لازم است
  - برای امنیت و پایداری، وب‌سایت نباید مستقیماً به چاپگرها متصل شود. برنامهٔ Bridge در محیطی قرار دارد که درایور چاپگر نصب است و چاپ محلی را انجام می‌دهد.

- نحوهٔ ارتباط با وب‌سایت
  - ارتباط از طریق API مبتنی بر HTTP(S) و با استفاده از یک توکن دستگاه (Device Token). Bridge درخواست شغل بعدی را می‌گیرد، چاپ می‌کند و نتیجه را به سرور اعلام می‌کند.

- معماری کلی
  - وب‌سایت (مدیریت سفارش‌ها و صف چاپ) <--> Print Bridge (پولینگ API، چاپ محلی) <--> چاپگر حرارتی

---

2. راهنمای نصب

حداقل نیازها
- ویندوز 10 یا جدیدتر (یا ویندوز سرور)
- در صورت استفاده از نسخهٔ مبتنی بر .NET، فریم‌ورک .NET 6 یا 7 نصب باشد.
- درایور چاپگر حرارتی نصب شده باشد.

مراحل نصب (مثال برای برنامهٔ .NET):
1. فریم‌ورک .NET مناسب را نصب کنید: https://dotnet.microsoft.com/download
2. فایل‌های برنامه را در فولدری مانند `C:\PrintBridge` قرار دهید.
3. فایل پیکربندی JSON کنار اجرایی ایجاد کنید و آدرس سرور و توکن را تنظیم کنید.
4. برنامه را یک‌بار به‌صورت تعاملی اجرا کنید تا اتصال به سرور و فهرست چاپگرها تست شود.
5. در صورت نیاز، برنامه را به‌عنوان سرویس ویندوز ثبت کنید یا با Startup اجرا کنید.

اجرای برنامه
- برنامه را مستقیماً اجرا کنید یا با ابزارهایی مانند sc.exe یا NSSM آن را به‌عنوان سرویس ثبت کنید.

---

3. تنظیمات

پارامترهای مهم:
- Server URL: آدرس کامل به `api/print_bridge.php` در سرور
- Device Token: توکن محرمانه که Bridge را احراز هویت می‌کند
- Polling Interval: فاصلهٔ زمانی پولینگ (ثانیه) — پیشنهاد: 2 تا 10 ثانیه
- Default Printer: نام چاپگر ویندوزی
- Test Print: قابلیت چاپ آزمایشی بدون مصرف شغل
- Start With Windows: روشن‌کردن خودکار

نمونهٔ JSON پیکربندی
{
  "server": "https://my-cafe.local/api/print_bridge.php",
  "token": "YOUR_DEVICE_TOKEN",
  "pollIntervalSec": 5,
  "printer": "EPSON TM-T20",
  "autoStart": true,
  "logPath": "C:\\PrintBridge\\logs"
}

نکات:
- آدرس سرور باید به endpoint کامل اشاره کند. Bridge اکشن‌ها را به صورت query string اضافه می‌کند.
- توکن را محرمانه نگه دارید و در محیط تولید آن را امن ذخیره کنید.

---

4. تنظیم چاپگر

انتخاب چاپگر
- Bridge باید چاپگرهای نصب‌شده در ویندوز را نشان دهد تا کاربر یکی را انتخاب کند.

چاپگرهای پشتیبانی‌شده
- چاپگرهای حرارتی 58mm و 80mm (معمولاً ESC/POS یا درایور ویندوزی)
- اتصال USB، LAN و WiFi پشتیبانی می‌شود اگر درایور ویندوز نصب باشد.

نکات عملی
- در صورت نیاز به کنترل بیشتر (مثلاً برش کاغذ یا دستور ESC/POS)، برنامه باید دستورات مخصوص چاپگر را ارسال کند.
- قبل از فعال‌سازی چاپ خودکار، چاپ آزمایشی انجام دهید.

---

5. یکپارچه‌سازی با وب‌سایت (نحوهٔ ایجاد و مصرف شغل‌ها)

- وقتی ادمین در پنل وضعیت سفارش را به `approved` تغییر می‌دهد، وب‌سایت یک رکورد شغل چاپ ایجاد می‌کند (print_jobs) با وضعیت `pending`.
- Bridge شغل‌های pending را درخواست و یکی را به‌صورت اتمی در وضعیت `processing` قرار می‌دهد تا از چاپ تکراری جلوگیری شود.
- فیلد `payload` شامل متن UTF-8 است که دقیقا همان محتوایی است که باید چاپ شود.
- پس از چاپ موفق، Bridge با API نتیجه را با `completed` تایید می‌کند.
- در صورت خطا، Bridge نتیجه را `failed` گزارش می‌دهد و `retry_count` افزایش می‌یابد.

---

6. مستندات API

همهٔ درخواست‌ها به `api/print_bridge.php` صورت می‌گیرند و نیاز به توکن دارند.

احراز هویت
- توکن را در هدر `X-Device-Token: <token>` یا پارامتر query `?token=` ارسال کنید.
- سرور توکن را با مقدار ذخیره‌شده در settings (کلید `print_bridge_token`) مقایسه می‌کند.

اکشن‌ها

1) دریافت و claim شغل بعدی
- URL: GET /api/print_bridge.php?action=next
- پاسخ (مثال):
{ "job": { "id": 123, "order_id": 987, "order_number": "DNJ-...", "payload": "...", "paper": "80", "created_at": "...", "retry_count": 0 } }
- اگر شغلی نباشد: { "job": null }

2) تایید نتیجه چاپ
- URL: POST /api/print_bridge.php?action=confirm
- بدنه (JSON): { "job_id": 123, "result": "completed" }
- یا در صورت خطا: { "job_id": 123, "result": "failed", "error": "Printer offline" }
- پاسخ: { "ok": true }

3) لیست شغل‌های pending (برای دیباگ)
- URL: GET /api/print_bridge.php?action=pending_list
- پاسخ: لیست سادهٔ شغل‌های pending

خطاها
- 401 Unauthorized — توکن نامعتبر
- 400 Bad Request — دادهٔ ناقص
- 500 Server Error — مشکل سروری

7. عیب‌یابی

مسائل معمول و راه‌حل‌ها:
- چاپگر دیده نمی‌شود
  - درایور چاپگر را نصب و از Notepad چاپ تست انجام دهید.
- چاپگر آفلاین یا کاغذ تمام شده
  - وضعیت چاپگر و رول کاغذ را بررسی کنید.
- توکن نامعتبر
  - مقدار `print_bridge_token` در جدول settings را بررسی کنید.
- شغل دریافت نمی‌شود
  - سفارش باید در پنل ادمین تایید (approved) شود تا شغل ایجاد شود؛ جدول print_jobs را بررسی کنید.
- جلوگیری از چاپ تکراری
  - سرور شغل را به `processing` تغییر می‌دهد؛ اگر چاپ تکراری دارید بررسی کنید که Bridge بعد از چاپ، job را completed می‌کند.

لاگ‌ها
- لاگ‌های Bridge را فعال کنید؛ آن‌ها HTTP و خطاهای چاپگر را ثبت می‌کنند.

---

8. امنیت

- توکن دستگاه
  - توکن محرمانه است؛ آن را ایمن نگهدارید و دوره‌ای تعویض کنید.
- ارتباط امن
  - از HTTPS برای انتقال اطلاعات استفاده کنید.
- توصیه‌ها
  - Bridge را در شبکهٔ محلی قرار دهید و دسترسی سرور را محدود کنید.

---

9. بروزرسانی

- تغییرات سروری
  - فیلدهای پاسخ (id, payload, paper, order_number) را تغییر ندهید مگر اینکه Bridge نیز بروزرسانی شود.
- بروزرسانی Bridge
  - سرویس را متوقف، باینری را جایگزین و سرویس را راه‌اندازی مجدد کنید.

---

10. پرسش‌های متداول

س: متن چاپ به چه زبانی است؟
ج: متن به فارسی (UTF-8) و مناسب چاپ RTL است.

س: آیا قیمت‌ها چاپ می‌شوند؟
ج: خیر. محتوای چاپ فقط برای آماده‌سازی سفارش است و اطلاعات مالی چاپ نمی‌شود.

س: چگونه عرض کاغذ را تنظیم کنم؟
ج: فیلد `paper` در شغل ('58' یا '80') مشخص است؛ Bridge می‌تواند بسته به مقدار آن فونت/حاشیه را تغییر دهد.

ضمیمه: تنظیم توکن در سرور

- اگر رابط تنظیمات وجود ندارد، از SQL استفاده کنید:

UPDATE settings SET setting_value = 'YOUR_TOKEN' WHERE setting_key = 'print_bridge_token';

یا یک اسکریپت PHP یک‌باره:

<?php
require_once __DIR__ . "/classes/Setting.php";
Setting::set('print_bridge_token', 'YOUR_TOKEN');


پایان سند.
